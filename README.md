# Baseball Motion Lab

カメラ映像から野球動作の**関節角度を数値化**し、**文献の基準値と比較**するブラウザアプリ。
映像はすべて端末内で処理され、外部に送信されません。

## できること

- **19種類の関節角度をリアルタイム計測** — 肘・肩（挙上／水平内外転）・股関節・膝・足首・体幹（傾斜／側屈／前後傾）・肩と骨盤の回旋・捻転差（X-Factor）・頭部
- **映像への角度の重ね描き** — 骨格と角度の弧を実映像に重ねて表示
- **記録とグラフ化** — 角度の時系列をスクラブ再生、CSV出力
- **動画ファイルの一括解析** — 撮影済みの動画を全フレーム解析
- **ボールの検出・追跡** — 投球の入射角、打球の打ち出し角、インパクト時刻の自動推定
- **文献基準値との比較** — インパクト／踏込足接地の角度を論文の mean ± SD と照合
- **目標アタックアングルの算出** — 体格・レベル・球種から目標値を出し、実測のスイング軌道角と比較
- **オフライン動作** — 初回ダウンロード後は通信なしで起動（4G/現場での利用を想定）

## 使い方

```bash
./fetch-assets.sh     # 任意。完全オフラインで使いたい場合のみ
python3 server.py 8777
```

<http://localhost:8777> を開く。カメラは `localhost` または HTTPS でのみ利用できます。

`fetch-assets.sh` を実行しない場合、モデルとランタイムは CDN から取得されます（初回のみ）。

### 撮影位置

計測したい角度によって最適なカメラ位置が変わります。

| 見たいもの | カメラ位置 |
|---|---|
| スイングのアタックアングル、肘・膝の角度 | 打者の**真横**（投球方向に直角） |
| 体の開き、肩・骨盤の回旋、捻転差 | 打者・投手の**正面または背面** |
| 投球フォーム全体 | 三塁側／一塁側から全身が入る位置 |

回旋角は「構えの姿勢を基準(0°)にセット」を押してから記録すると、文献と同じ基準で比較できます。

## 数値の出所

アプリ内の「出典」タブに全て表示されます。3層に区別しています。

| ラベル | 意味 |
|---|---|
| **文献値** | 査読論文・学位論文の mean ± SD をそのまま使用 |
| **文献の関係式** | 論文が示した関係を内挿 |
| **体格補正(推定)** | 体格からの補正。**当アプリの推定であり検証されていない** |

主な出典:

- Fortenbaugh, D. M. (2011). *The Biomechanics of the Baseball Swing*. 博士論文, University of Miami.
  接触時（BC）の角度: 踏込脚膝屈曲 18±4°、後ろ肘屈曲 81±8°、前肩挙上 70±4°、骨盤回旋 77±6°、上胴回旋(対骨盤) −2±4°
- Fleisig, G. S. ら の投球バイオメカニクス基準値 — 足接地時の踏込脚膝屈曲 38±9°、リリース時肘屈曲 29±6°、肩外転 約90°
- Nathan, A. M. / ABCA Inside Pitch (2019) — 速球の入射角 約−6°、変化球 約−10°。最適アタックアングルは概ね +2〜+14°で、バットスピードが遅いほど大きい
- Winter, D. A. / De Leva (1996) — 身長からの体節長比

### 「身長・体重から理想の角度」について

**身長・体重を入れると理想の関節角度が出る、という検証済みの回帰式は文献に存在しません。**
本アプリの目標アタックアングルは、次の組み合わせによる推定です。

1. 論文が示した「バットスピードが速いほど最適アタックアングルは小さい」という関係（文献の関係式）
2. 競技レベル別のバットスピード目安に、身長・体重で補正をかけたもの（**当アプリの推定・未検証**）

バットスピードの実測値があれば必ず入力してください。推定より精度が上がります。

## 計測上の限界

- 単眼カメラの奥行き(z)は推定値です。回旋角・水平内外転角は撮影方向に強く依存します。
- **肩の内外旋**（投球で重要な最大外旋角）は、この33点のランドマークからは計測できません。
- 30fps では投球・打球のボールは1フレームで大きく移動しブレるため、検出率が落ちます。**120fps以上のスロー撮影を推奨**します。
- ボールの追跡は「フレーム間差分による動体検出 + 等速度モデル」が主体で、物体検出モデルは補助です。背景が動く映像（手持ち撮影、観客席）では誤検出が増えます。三脚固定を推奨します。
- スイング軌道角はバットではなく**両手首の中点（グリップ）の軌道**から算出した近似値です。
- 比較対象の論文は成人の上級者を対象としています。成長期の選手にそのまま当てはめないでください。

## モバイル・低速回線での動作

- 端末と回線を判定し、モデル・解像度・処理レートの既定値を自動で決めます
- モデルは Cache Storage に保存され、2回目以降は通信ゼロで起動します
- 「オフライン用に一括ダウンロード」で Wi-Fi のうちに取得しておけます
- Service Worker によりアプリ本体もオフラインで起動します

## 構成

```
index.html          UI
js/app.js           メイン（入力・描画・記録・UI）
js/metrics.js       角度の定義と計算（19種類）
js/geom.js          ベクトル演算
js/ball.js          ボール検出・追跡・軌道解析
js/reference.js     文献基準値と体格補正モデル
js/chart.js         時系列グラフ
js/loader.js        モデル読込・キャッシュ・回線判定
js/config.js        配信元（ローカル / CDN）の切替
sw.js               Service Worker
server.py           開発用サーバ（gzip・スレッド化）
tests/test.html     検証（幾何計算42項目 + 実写画像での姿勢推定）
```

## テスト

<http://localhost:8777/tests/test.html> を開く。合成ランドマークによる角度計算の検証42項目と、実写画像での姿勢推定を実行します。
